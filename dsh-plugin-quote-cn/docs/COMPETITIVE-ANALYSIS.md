# 竞品分析与借鉴 — dsh-plugin-quote-cn

> 调研对象：两款雪球生态浏览器插件。结论服务于本插件的差异化定位：**宿主内闭环的行情面板 + 模型可调用的行情工具**。

---

## 1. 竞品 A：雪球组合盯盘助手（"跟着大佬做投资（投机）"）

- 来源：[Chrome 商店](https://chromewebstore.google.com/detail/mjdalloebfopianpnhncgnoafcfnimfa?hl=zh-CN) · [官网](https://xueqiuzuhe.com/) · [Gitee](https://gitee.com/abudula7/xueqiuzuhe)
- 开发者：个人（"长角"），v0.2.2（2026-01），Chrome/Edge，11MB，免费
- 定位：跟踪雪球组合调仓/持仓 + 通用盯盘，独立 Popup/SidePanel 形态

### 功能拆解

| 模块 | 功能点 |
|---|---|
| 实时行情与提醒 | 组合调仓/持仓异动通知；股价与基金净值实时更新；分时图、K 线、行情"看点" |
| 专业组合分析 | 业绩与风险指标；完整调仓历史；持仓结构与权重；多组合对比、多维图表 |
| 投资机会发现 | 热门组合榜单与推荐；股票/基金/组合/主理人一键搜索；主理人动向跟踪 |
| 个性化 | 全尺寸/迷你模式；自定义分组排序；灰色模式；红绿涨跌色切换 |
| 多市场 | A 股、港股、美股 |

### 模式要点

- 独特卖点在"跟投"：监控他人组合调仓，与雪球官方提醒互补。
- 弱点：个人项目迭代慢；强依赖雪球非官方接口；11MB 偏重。

## 2. 竞品 B：套利工具箱（LOF/ETF 溢价套利）

- 来源：[Chrome 商店](https://chromewebstore.google.com/detail/oamngdjhbebmcojollcocmmkbldnepoa) · [GitHub](https://github.com/jackluson/arbitrage-toolbox-extension) · 官网 anchor-data.cn/arbitrage-toolbox
- 开发者：个人（JackyLu），Manifest V3，3.5MB，免费 + 墨滴专栏内容营销
- 定位：页面注入型（content script），在雪球/集思录/天天基金页面上"贴"数据

### 功能拆解

- 雪球行情页：ETF/LOF 溢价率、实时估算溢价率、申购限额、份额变动、成交额、市值
- 集思录 LOF/QDII 页：**QDII-LOF 实时估值溢价率**（基于跟踪指数当日表现估算，弥补 T-2 净值延迟）——集思录被要求下线估值数据后的"补位者"
- 详情页：**跟踪比**（净值 vs 跟踪指数涨幅）；跳转同花顺/东财/集思录

### 模式要点

- 页面增强形态，零学习成本，跟着用户已有工作流走。
- **最有价值的启示：衍生指标 > 原始指标。** 上游数据下线/缺失时自己算（估算溢价率、跟踪比），形成独占数据。
- 跨源聚合拼出决策链路（溢价→限购→份额→下单跳转）。

## 3. 两者模式对比

| 维度 | 盯盘助手 | 套利工具箱 |
|---|---|---|
| 形态 | 独立面板 | 页面注入 |
| 场景 | 跟投监控 + 挂机盯盘 | 到页面上做套利决策 |
| 数据源 | 单一（雪球） | 多源融合（雪球+集思录+天天基金） |
| 数据加工 | 展示层为主 | 计算层（自研估算模型） |
| 时效价值 | 事件提醒 | 实时决策输入 |

共同风险：强依赖非官方接口/页面 DOM，需要抽象数据层 + 降级方案（我们的 provider 链已具备）。

## 4. 为我们所用

### 4.1 指标层（P0，本轮实现）

竞品是纯展示插件，无法把指标"喂给模型"；我们的差异化主场是**衍生指标进 `quote_get` 工具输出**，模型分析质量直接提升。

| 衍生指标 | 定义 | 数据来源 | 竞品出处 |
|---|---|---|---|
| 振幅 amplitude | `(high - low) / prevClose` | 快照字段 | 盯盘助手行情面 |
| 日内位置 dayRangePos | `(price - low) / (high - low)`，0~1 | 快照字段 | 套利工具箱"决策输入"思路 |
| 相对大盘超额 relativePct | `pct - 上证指数 pct` | 快照 + sh000001 | 同上 |
| 52 周位置 pctFrom52wHigh / 52wLow | 现价距 52 周高/低点的百分比 | `kline(day, qfq, 250)` | 盯盘助手"多维图表" |
| N 日均线偏离度 maDev | `(price - MA_N) / MA_N`，N = 20/60/120 | `kline(day, qfq, 130+)` | 本轮补充需求 |

实现要点：

- 服务端新增 `derived` 字段挂在 `Quote` 上；快照类指标同步算，K 线类指标（52 周位置、均线偏离）走 `kline()` 现有缓存（10 分钟 TTL），对上游零额外压力。
- 指标计算失败不影响基础快照返回（字段缺省），保证降级安全。
- MA 用前复权收盘价；`derived` 整体作为可选字段进工具 output schema 与渲染。

### 4.2 功能层（后续阶段）

| 优先级 | 事项 | 借鉴来源 | 成本 |
|---|---|---|---|
| ✅ P0 | 衍生指标包（振幅/日内位置/相对上证/52周/MA偏离）进工具与 UI | 套利工具箱"计算层" | 已落地 |
| ✅ P1 | 拖拽排序 + 收起行振幅/换手/日内位置条 | 盯盘助手"自定义排序" | 已落地 |
| P1 | 阈值提醒（host 轮询已具备，可让模型主动播报） | 盯盘助手核心留存功能 | 2-3 天 |
| P1 | 自选分组 + compact 密度模式 | 盯盘助手"迷你模式/分组" | 1-2 天 |
| P2 | 涨跌幅色块 + 灰度/红绿切换 | 盯盘助手（灰度下仍可辨识） | 半天 |
| P2 | 量比、流通市值等字段补全 | 盯盘助手行情面 | 依赖 provider 字段核对 |
| P3+ | ETF/LOF 溢价率（需净值数据源） | 套利工具箱 | 高 |
| 不做 | 跟投组合监控、页面注入、外站跳转 | — | 非主场 |

### 4.3 布局层

- watchlist 行结构：`名称 现价 涨跌幅(色块) 振幅/换手(次要灰字) sparkline`。
- 主页分区顺序：指数总览 → （未来）提醒摘要条 → 自选。
- 工具卡片：竞品没有对话式卡片；快照卡片可加关键指标 chip（PE/PB/振幅/均线偏离）——我们独有形态。
